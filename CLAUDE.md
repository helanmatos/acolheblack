# Projeto acolheblack

## Sobre o projeto
Site do programa ACOLHE — apoio psicossocial e assistência jurídica
a vítimas de racismo, iniciativa da Universidade Zumbi dos Palmares.

## Estrutura de arquivos
- `index.html` + `components.jsx` — página inicial
- `acolhimento.html` + `acolhimento.jsx` — página de acolhimento
- `juridico.html` + `juridico.jsx` — página jurídica
- `instituto.html` + `instituto.jsx` — página do instituto
- `chrome.jsx` — nav, footer e constantes globais (WHATS_URL, PHONE…)
- `style.css` — estilos globais

## Tecnologia
Site estático com React 18 via CDN + Babel Standalone (sem build).
Supabase JS v2 via CDN para formulários.
